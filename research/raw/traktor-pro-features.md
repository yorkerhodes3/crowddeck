# traktor-pro-features

QUERY: Native Instruments Traktor Pro 4 features Stem Deck Pattern Player remix decks

## Synthesized answer
Native Instruments Traktor Pro 4 is a four‑deck DJ platform that combines traditional mixing tools with advanced creative features: it includes Remix Decks that let you load and trigger samples, loops and stem files on any deck, and a built‑in Pattern Player that provides up to four independent drum‑machine units with 17 kits and step‑sequencing for polyrhythmic patterns; the software also offers AI‑powered stem separation (iZotope RX) with independent volume, filter and FX control for each stem, flexible beat‑grid detection and editing, tempo and beat sync modes, 43 built‑in effects across nine mixer/channel slots, Auto‑Master, key‑lock, hot‑cues/loops, DVS timecode support and full integration with external MIDI, Ableton Link and compatible controllers.

## Create on-the-fly remixes with the Pattern Player

You can easily create a remix in real time using Traktor’s Stems, a second track, and drums from the Pattern Player. To do this, choose one track that will be the main track that you’ll use the drums, bass, and melody from.

Loop a section of the track that doesn’t have vocals on it. Load this track into Deck B.

Choose a second vocal track in a compatible key. You’ll use this as the vocal for the remix.

Create a Stem track for that track and load it into Deck A. Turn off the drums and bass, so only the vocal and other small instrumentation parts are playing.

Traktor Pattern Player

The Pattern Player is an innovative tool introduced in Traktor Pro 4 that allows DJs to integrate rhythmic patterns into their sets seamlessly. This groundbreaking effects unit delivers an extensive library of drum kits and rhythmic sequences, drawing inspiration from legendary drum machines and the signature drums of leading electronic producers.

The Pattern Player empowers DJs to layer intricate percussive elements directly onto their tracks and craft dramatic build-ups, explosive breakdowns, and transitions that go beyond conventional beat matching. When the Pattern Player is assigned to a deck, DJs can manipulate volume, pitch, and decay parameters, and add Traktor Pro 4’s effects for a truly unique sound.
