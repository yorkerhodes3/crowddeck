QUERY: DJ streaming integration Beatport LINK Beatsource TIDAL SoundCloud Go+ API terms for DJ apps

## Synthesized answer
Beatport LINK and Beatsource LINK are both built‑in streaming options on Denon’s Engine OS hardware (Prime 4, Prime Go+, SC Live 2/4, Mixstream Pro +, etc.) and are also supported as official integrations in major DJ software such as Serato DJ Pro/Lite, Rekordbox, VirtualDJ, Traktor Pro 3, DJUCED, djay Pro (desktop and iOS), and Engine DJ OS, allowing DJs to stream full‑track, high‑quality audio directly from the catalog without needing local downloads; Tidal is likewise integrated across those same platforms, offering Hi‑Fi lossless streams where the DJ software supports it. SoundCloud Go+ is available in djay Pro, Serato, Rekordbox and other leading apps, but developers must obey SoundCloud’s API Terms of Use, which require a registered app with a client ID, enforce usage quotas, and prohibit accessing Go‑only content unless the developer has a separate written agreement with SoundCloud that includes robust authentication; the API also mandates proper attribution (crediting the uploader, SoundCloud and providing permalink backlinks) and forbids circumventing any imposed limits. Beatport’s streaming service (Beatport Streaming) now lists a wide range of DJ integrations—including CDJ‑3000/X, DEX, djay Pro, DJ Studio, DJUCED, Engine OS, future.dj.pro, OMNIS‑DUO, OPUS‑QUAD, rekordbox, Serato, Traktor, Tribe XR, VirtualDJ, WeDJ and XDJ‑AZ—offering unlimited full‑track playback and, where supported, real‑time stem separation. Beatsource is being merged into Beatport and while legacy Beatsource subscriptions still work, new users are directed to Beatport LINK for open‑format music. All of these services require an active subscription and, where applicable, a stable Wi‑Fi connection on the hardware or computer running the DJ software.
